# STANDARDS.md

## BAIS:3300 - Digital Product Management · Module 8 \| Personal Landing Page Project

## 1. Project Overview

This project is a single-page professional landing page for Colby Davis,
a Business Analytics and Finance student at the University of Iowa. The
site is designed for recruiters at mid-to-large companies and aims to
clearly communicate his technical skills, project experience, and
leadership background. A successful outcome is a clean, professional
website that quickly demonstrates his value and drives recruiters to
view his LinkedIn profile.

## 2. Technical Standards

Languages and versions: - HTML5 (semantic elements required) - CSS3
(external stylesheet only)

Folder structure: /your-website-project\
├── index.html\
├── /css\
│ └── stylesheet.css\
├── /js\
│ └── scripts.js\
├── /images\
│ └── headshot.jpg

Framework: - No framework --- vanilla CSS only

Architecture: - Static single-page site - No JavaScript or backend -
External stylesheet required - Images stored locally

Responsiveness: - Fully responsive (320px+) - No horizontal scrolling

Accessibility (WCAG 2.2 AA): - Alt text required - Proper heading
hierarchy - Strong color contrast - Keyboard navigable links

Security: - External links open in new tab with rel="noopener
noreferrer"

## 3. Design Standards

Color palette: - Background: #F8F9FA - Primary text: #212529 - Accent:
#1D4ED8 - Secondary background: #E9ECEF

Typography: - Font: Inter (Google Fonts) - Body: 1.1rem, line height
1.6 - H1: 1.75rem bold - H2: 1.3rem bold (accent color)

Imagery: - Professional headshot only

Layout: - Max width: 800px centered - Sticky navigation bar - 60px
section spacing - Mobile: single column - Desktop: two-column project
layout

Components: - Profile photo: circular, centered - Skill tags:
pill-shaped badges - Contact links: labeled icons (LinkedIn + email) -
Navigation: simple text links

Tone: - Professional, Approachable, Data-driven - First person, concise,
results-focused
